# Dart Learning — lesdev

Репозиторий для изучения языка Dart: теория, короткие примеры и практические упражнения.

## Структура

- `bin/lesdev.dart` — стартовая программа.
- `lessons/` — конспекты и примеры по темам.
- `exercises/` — практические задания.

## Как запустить

Установи [Dart SDK](https://dart.dev/get-dart), затем выполни:

```bash
dart run
```

## План обучения

1. Переменные и типы данных
2. Операторы и условия
3. Циклы
4. Функции
5. Коллекции: List, Set, Map
6. Классы и объекты
7. Null safety
8. Асинхронность: Future и async/await
